# Security and Privacy

Do not publish the following in issues, pull requests, commits, or releases:

- passwords, API keys, tokens, private keys, or database URLs;
- NIM, respondent identity, consent forms, or personal data;
- raw research data or restricted paper PDFs;
- administrative documents, signatures, or scanned identity documents.

For suspected credential exposure, revoke the credential first, then report the
incident through a private channel to repository maintainers. Do not include the
secret in the report.

This repository is not an official UNESA support or policy channel.
