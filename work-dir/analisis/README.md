# Analisis Reproducible

Setiap analisis minimal mencatat:

- sumber dan checksum data input;
- versi software serta paket;
- perintah atau urutan eksekusi;
- parameter, seed, kriteria eksklusi, dan transformasi;
- output lengkap sebelum ringkasan;
- pemeriksaan asumsi dan diagnostik;
- reviewer serta tanggal verifikasi.

Jangan mengubah output manual untuk menyesuaikan narasi. Perbaiki script, jalankan
ulang, lalu catat perubahan.
