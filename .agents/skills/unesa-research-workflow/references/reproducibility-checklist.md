# Checklist Reproducibility

## Data

- [ ] Asal, tanggal akses, lisensi, dan checksum tercatat.
- [ ] Data mentah tidak pernah diubah in place.
- [ ] Definisi variabel dan missing values terdokumentasi.
- [ ] Kriteria inklusi, eksklusi, dan outlier tercatat sebelum interpretasi.

## Environment

- [ ] OS, runtime, package, dan versi tercatat.
- [ ] Seed dan parameter tercatat.
- [ ] Perintah eksekusi dapat dijalankan dari awal.

## Analisis

- [ ] Transformasi dibuat dengan script.
- [ ] Asumsi dan diagnostik disimpan.
- [ ] Output gagal, null, atau tidak signifikan tetap tercatat.
- [ ] Tabel dan gambar final dihasilkan tanpa edit angka manual.

## Naskah

- [ ] N, unit, periode, pembulatan, dan label konsisten.
- [ ] Setiap angka dapat ditelusuri ke output.
- [ ] Simpulan tidak melampaui desain dan bukti.
- [ ] Keterbatasan dilaporkan.
- [ ] Log AI dan pernyataan penggunaan AI cocok.
