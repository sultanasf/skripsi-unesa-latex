# Referensi Variabel

Semua variabel berada di `latex-work-dir/config/variables.tex`.

| Kelompok | Command |
|---|---|
| Mahasiswa | `\NamaMahasiswa`, `\NIM` |
| Tugas akhir | `\JudulPenelitian`, `\BentukTugasAkhir` |
| Institusi | `\NamaKota`, `\NamaFakultas`, `\NamaProgramStudi`, `\Jenjang`, `\Tahun` |
| Tanggal | `\TanggalPersetujuan`, `\TanggalUjian`, `\TanggalPernyataan` |
| Pembimbing | `\NamaPembimbing`, `\NIPPembimbing` |
| Penguji 1 | `\NamaPengujiSatu`, `\NIPPengujiSatu` |
| Penguji 2 | `\NamaPengujiDua`, `\NIPPengujiDua` |
| Penguji 3 | `\NamaPengujiTiga`, `\NIPPengujiTiga` |
| Dekan | `\NamaDekan`, `\NIPDekan` |
| Koordinator prodi | `\NamaKoordinatorProdi`, `\NIPKoordinatorProdi` |
| Abstrak | `\KataKunci`, `\Keywords` |
| AI | `\StatusPenggunaanAI`, `\AIExplorasiIde`, `\AIKerangkaTulisan`, `\AIPenyuntinganBahasa`, `\AIAnalisisData`, `\AIIlustrasi`, `\AILainnya` |

Gunakan `\CheckedBox` atau `\EmptyBox` pada variabel pilihan AI. Nilai wajib
mencerminkan penggunaan nyata dan cocok dengan `work-dir/ai/log.md`.
