# Aturan Format UNESA

## Terverifikasi dari DOCX

| Elemen | Aturan |
|---|---|
| Kertas | A5, 14,8 x 21 cm, 80 gram |
| Cetak | Bolak-balik |
| Font | Book Antiqua 10 pt |
| Margin | Kiri 2,5 cm; atas 2,5 cm; kanan 2 cm; bawah 2 cm |
| Spasi isi | Multiple 1,15 |
| Spasi khusus | Abstrak, daftar isi, kutipan langsung lebih dari 4 baris: tunggal |
| Bab | `BAB I`, judul ditulis kapital, tebal, rata tengah |
| Subbagian | Huruf kapital: A., B., C., dan seterusnya |
| Awal | Angka Romawi kecil |
| Inti dan akhir | Angka Arab mulai Bab I |
| Footer | Nomor halaman rata tengah |
| Sampul | Abu-abu `#5F5D5D`, aksen emas, logo UNESA |
| Abstrak | Satu halaman per bahasa, maksimal 250 kata |
| Pustaka | Hanya sumber dirujuk, urut alfabetis |

## Bahasa

- Gunakan Bahasa Indonesia atau Bahasa Inggris ragam ilmiah.
- Gunakan ejaan dan istilah baku, lugas, konsisten.
- Tulis unsur gramatikal lengkap dan imbuhan tersurat.
- Satu paragraf memuat satu ide pokok dan minimal dua ide pendukung.
- Jaga kohesi antarkalimat dan antarparagraf.
- Hindari persona `saya`, `kami`, dan `kita` pada isi ilmiah.

## Belum Eksplisit dalam DOCX

- Nama gaya sitasi.
- Format rinci caption, persamaan, algoritma, dan kode.
- Aturan heading setelah subbagian.
- Posisi nomor halaman ganjil dan genap yang berbeda.

Untuk unsur tersebut, pertahankan default workspace dan minta konfirmasi jika
perubahan memengaruhi penyerahan final.
