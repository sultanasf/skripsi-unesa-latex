# Format Status

Dokumen ini memisahkan aturan yang diketahui dari keputusan yang belum dipilih.

## Terverifikasi

- A5, Book Antiqua 10 pt, margin kiri/atas 2,5 cm, kanan/bawah 2 cm.
- Spasi 1,15; bagian awal Romawi; isi/akhir Arab.
- Proposal Bab I-III; skripsi penuh Bab I-V.
- Abstrak bilingual maksimal 250 kata.
- Sampul abu-abu `#5F5D5D` dengan logo UNESA.

## Masih Open

| Keputusan | Status | Bukti yang dibutuhkan |
|---|---|---|
| Gaya sitasi | open | Panduan prodi atau arahan pembimbing |
| Nomor tabel/gambar/persamaan | open | Contoh naskah terbaru atau panduan resmi |
| Level heading lanjutan | open | Panduan resmi |
| Front matter proposal | open | Ketentuan prodi |
| Cover proposal | open | Contoh cover resmi |
| Jumlah pembimbing/penguji | open | Form sidang mahasiswa |
| Format hasil statistik | open | Arahan metodologi/pembimbing |
| Turnitin dan etik | open | Kebijakan fakultas/prodi terbaru |
| Penggunaan AI | open | Pernyataan aktual mahasiswa dan kebijakan kampus |

Base template tidak mengubah status `open` menjadi keputusan normatif.
